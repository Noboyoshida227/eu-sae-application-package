# Code of Conduct

## Our commitment

Everyone who takes part in this project -- reporting an issue, asking a
question, proposing a change -- should be able to do so without harassment or
condescension. This project is used by statistical offices, researchers and
students across many countries, working in several languages and with widely
different levels of familiarity with small-area estimation. A question that
seems basic to one person is a real obstacle to another, and answering it well
is part of the work.

## Expected behaviour

- Be respectful and assume good faith.
- Give and accept criticism of the work, not of the person doing it.
- Be precise. "It failed" starts a long thread; the error text and the run
  label usually ends it.
- Respect confidentiality. Never post real microdata, personal data, or
  credentials in an issue or a pull request.

## Unacceptable behaviour

Harassment, discriminatory or demeaning comments, personal attacks, publishing
others' private information, and sustained disruption of discussions.

## Reporting

Report concerns to the maintainers through a private channel rather than a
public issue, or to github@worldbank.org. Reports will be reviewed and handled
discreetly. The World Bank organization's own code of conduct also applies to
activity in this repository.

## Scope

This applies in the repository -- issues, pull requests, discussions and
commits -- and to project spaces elsewhere where someone represents the
project.
